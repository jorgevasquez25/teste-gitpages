# Referências

- **OpenUP** — Eclipse Process Framework. Processo de desenvolvimento de software adotado pela equipe.
- **MoSCoW** — Técnica de priorização de requisitos (Must, Should, Could, Won't).
- **URPS+** — Modelo de classificação de requisitos não funcionais (Usabilidade, Confiabilidade, Desempenho, Suportabilidade e restrições).
- **LGPD** — Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018).
- **Sponte** — Sistema de gestão escolar citado na análise competitiva.
- **i-Educar** — Sistema de gestão educacional de código aberto citado na análise competitiva.
